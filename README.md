# Medical Booking System

A responsive clinic booking system built with Laravel, PHP, MySQL, Bootstrap, and JavaScript.

## Live Demo
🌐 https://medicalbooking.freedev.app

## Features
- Browse doctors and medical specialties.
- Book appointments online.
- Patient registration and login.
- Patient dashboard and profile management.
- Doctor dashboard for managing appointments.
- Ratings and contact page.

## Technologies Used
- Laravel
- PHP
- MySQL
- HTML5
- CSS3
- Bootstrap
- JavaScript
